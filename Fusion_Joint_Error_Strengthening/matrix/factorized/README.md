# Fully factorized information control

This control changes the conditioning model, including the correction mean, unlike the previous diagonal-penalty ablation. It retains exactly the original immutable observed blocks, masks, current contrast projections, complete maturity checks, history support/context/age weights, quality ridge and covariance estimation records.

First estimate the same global positive-definite `R` from complete jointly observed source blocks and the declared covariance regularizer. Set `D=diag(R)` before using any historical marginal likelihood. For each global physical source `s`, set `lambda_s=(q_s/mean(q))/sigma_p^2 + sum_{j:s observed}a_j/R_ss`, `mu_s=[sum_{j:s observed}a_j*z_js/R_ss]/lambda_s`, and `P=diag(1/lambda_s)`. Only after this global coordinate-wise conditioning restrict `mu,D,P` to the current source IDs. Use these three matrices in the unchanged paid-value objective, readiness check, convex solver and delayed issued-score calibration.

The formula follows by expanding the penalized least-squares objective with diagonal working covariance: every marginal inverse is diagonal, its quadratic and linear terms sum independently in each observed coordinate, and the diagonal quality ridge supplies the positive initial coordinate precision. Thus it is exactly factorized masked GLS, without filling missing errors. When full `R` is diagonal it coincides with the original joint-precision conditioning; otherwise both the mean and uncertainty can differ. The old `precision_diagonal` arm instead retains the full joint correction mean and only diagonalizes penalty matrices after conditioning, so it cannot isolate this change.

The callable module `factorized_control.py` exposes `core`, `factorized_state`, and `factorized_forecast`. Its `core` supports `precision_joint`, `gls_exact`, `block_sandwich` and `factorized_information`. Generate streams with this `core.augment` to include the factorized state fields, then use `core.initial_q` and `core.run` with `factorized_information`. Physical prefix data are passed normally; no model or frozen source is changed on disk.

The RSS experiment is a declared known-trace extension. Before evaluating this control, `protocol.json` freezes the formula, source hashes, original nine prior-scale/calibration-floor settings, three calibration delay arrangements (27 evaluations), unchanged selection rule, five test delays, and the original budget/reserve diagnostic grid. Existing matrix scripts and results remain unchanged. The local information intervention uses every original full-controller RSS state and its original prior scale and issued threshold, but rebuilds mean and precision under the factorized working covariance.

Run with bundled Python: `run_factorized.py --phase freeze`, then `--phase calibrate`, then `--phase test`. Output files are confined to this directory. Results cannot be overwritten by a subsequent execution. Full calibration outcomes, all local states, all changed actions and gain/loss decompositions are retained. Independent request-level service and fork reconstruction verify test results; all budget trajectories are reconstructed against the same ledger guarantee. Five delays share one physical trace, and this extension is not independent evidence for a newly acquired task.
