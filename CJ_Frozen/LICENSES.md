# Attribution and provenance

HARTH dataset,
[UCI repository](https://archive.ics.uci.edu/dataset/779/harth),
[DOI 10.24432/C5NC90](https://doi.org/10.24432/C5NC90).
The frozen official metadata records the dataset license as CC BY 4.0.
The unchanged adapter records source rows, simultaneous sensor timestamps,
subsampling, participant roles and causal lag histories. The cache is a
deterministic derivation; acquisition and consumed CSV hashes are retained in
its metadata and acquisition record. The approximately 296 MB raw archive is
not included, and reproduction from the processed cache needs no download.

PDF: Cao et al., [Predictive Dynamic Fusion](https://proceedings.mlr.press/v235/cao24c.html),
ICML 2024. QMF: Zhang et al.,
[Provable Dynamic Fusion for Low-Quality Multimodal Data](https://proceedings.mlr.press/v202/zhang23ar.html),
ICML 2023. The external controls adapt active author objectives to nonlinear
tabular source encoders. Original image/text architectures and benchmark
performance are not reproduced. Extra encoder computation is not claimed to
have identical measured hardware cost. Author commit identities are recorded
in the unchanged external protocol.

Scientific code copyright and any underlying licenses remain with their
respective authors. This package preserves source identity and attribution;
it does not replace the original projects' license terms.
