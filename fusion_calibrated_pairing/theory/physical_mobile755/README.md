The exact 58-source closure and declaration files are checked by `run_mobile755.py verify`. The conditional law, calibration V2, original-objective PDF/QMF tabular adapter code, published DBF operator, shared service contract and Fixed130 guard are unchanged from the authorized OPPORTUNITY protocol. The dataset adapter and declared partition are the only new physical implementation. The calibration grid is the same nine configurations for every arm, with three shared selection-delay schedules; all ties and all outcomes are retained.

All 31,991 records are retained in original ordinal order. The frozen fit/state-fit/score-fit/selection/test counts are 9,597/3,199/3,199/3,199/12,797. The first four stages contain only native Activity code 1. The test contains 571 code-0 records and 12,226 code-1 records. No source/class/row change or split revision followed this observation. There are no participant/site/device IDs in the CSV, and timestamp units are not established by the metadata. This is an independently collected phone collection with an ordinal holdout; it is not a participant/site-disjoint study or a validated physical-duration deployment.

The paired and five internal information controls have zero actual admissions and zero mean paid increment. PDF/QMF/DBF each have two harmful admissions, pooled loss 15 and mean paid increment −3. The paired-minus-external mean difference is +3 from avoided losses only; all five internal control differences are zero. There are six common beneficial potential leases worth 77 units, and none is admitted by any arm. These outcomes do not demonstrate additional beneficial joint-information actions or calibrated profitable admission. Undefined admitted coverage is retained as undefined rather than converted to 100%.

Commands below run from this folder, using the workspace Python runtime or an environment with NumPy and the declared original dependencies:

```sh
python run_mobile755.py verify
python analyze_mobile755.py
python finalize_mobile755.py
```

`process`, `calibrate` and `test` are write-once stages: they refuse to replace delivered inputs, selections or results. A full numerical rerun requires a clean mirrored workspace with the same verified numerical sources and official archive, and empty output locations. Run those stages in order, preserving the recorded authorization and raw-access chronology. Frozen source verification contains absolute paths; any relocation requires an explicitly verified path mapping rather than silently changing the recorded source hashes. Analysis and audit scripts only read the stored outcomes and do not perform tuning, training or test reselection.

The callback poison audit fixes issued forecasts, changes complete future callbacks after three declared cutoffs, and verifies every earlier issued calibrated score/proposal unchanged. It does not claim that source training ignores individually arrived labels. Individual model updates may consume their own arrived labels; paired aggregate state and calibration use fully matured complete-lease tuples.
